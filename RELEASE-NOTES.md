# Вперёд / Vpered 1.3.0

Платежи по дням и настраиваемые локальные напоминания.

## Что добавлено

- **День оплаты или дохода.** Необязательный день месяца для ежемесячных и разовых записей. Если в месяце нет указанного числа, используется последний день месяца.
- **Платежи по дням.** Ближайшие 30 дней, просроченные платежи и платежи выбранного месяца. Каждый счёт отображается в своей валюте.
- **Оплачено / Получено.** Отметка действует только для выбранного месяца, её можно отменить. Она не меняет месячный прогноз и не списывает деньги повторно.
- **Напоминания на Android.** Для каждого расхода: за сколько дней напоминать (0–365), местное время и дополнительное напоминание в день оплаты. Оплаченные, удалённые и пропущенные платежи исключаются из расписания. Изменения сумм учитываются автоматически.
- Русский и английский интерфейс, светлая и тёмная темы. Бюджеты из предыдущих версий загружаются без изменения сумм; даты им автоматически не присваиваются.

## Как включить

1. Откройте расход и задайте **День месяца**.
2. Включите **Напоминать об оплате**, выберите число дней и время.
3. На Android в разделе **Платежи по дням → Напоминания** нажмите **Включить уведомления** и разрешите их в системе. Включение действует для всех счетов. Кнопка **Проверить уведомление** планирует тест через 10 секунд.

Расписание работает локально, без интернета и подключения к ПК. На Windows доступен список платежей при открытом приложении; фоновые уведомления в этой версии поддерживаются на Android.

Android может задерживать уведомления из-за системных ограничений. Если нужно, разрешите точные напоминания кнопкой **Настроить точное время**. Расписание формируется на год вперёд, максимум 256 ближайших уведомлений; платежи с одинаковым временем группируются. Приложение показывает срок покрытия и продлевает расписание при открытии. Открывайте его также после смены часового пояса. Принудительная остановка приложения может блокировать уведомления.

## Установка и обновление

- Windows x64: **Vpered-Setup-1.3.0.exe**.
- Android 7+: **Vpered-1.3.0-Android.apk**; тот же ключ подписи, versionCode 3.
- Сначала сохраните резервную копию через **Сохранить файл**, затем установите поверх предыдущей версии. Не удаляйте приложение перед обновлением.
- Старые резервные копии поддерживаются. Файлы, сохранённые в 1.3, используют новый формат с датами и отметками и не загружаются в 1.2.
- Windows-установщик не имеет сертификата издателя. APK устанавливается из файла. iPhone не поддерживается.

## Проверки и ограничения

62 автоматических теста: расчёты, переводы, миграция, даты, отметки оплаты и взаимодействие с API уведомлений через тестовые подстановки. TypeScript/Vite, Windows и Android release builds. Проверка Windows-приложения в отдельном профиле: сохранение и перезапуск, RU/EN, тёмная тема и мобильная ширина. Подпись и разрешения APK проверены; разрешения на интернет нет.

Фактическая доставка уведомлений на физическом Android-телефоне ещё не проверена. Прогноз остаётся месячным: новый раздел показывает сроки платежей, а не точный остаток на каждый день.

## English

Optional payment days, upcoming/overdue lists and paid/received marks. Android reminders support 0–365 days of advance notice, a local time and an optional due-day reminder. They work offline and are rescheduled when saved data changes. Windows shows the payment list in the app; background alerts are Android-only. Existing budgets migrate without changing amounts. Back up before upgrading. Physical Android delivery has not yet been tested.
