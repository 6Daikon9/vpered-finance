# Вперёд / Vpered 1.2.0

Минорное обновление для Windows и Android.

## Что изменилось

- **Тёмная тема.** Переключатель рядом с языком. Выбор сохраняется на устройстве после перезапуска; тема охватывает формы, таблицы и мобильную навигацию.
- **Раздельные категории.** Доходы предлагают категории доходов, расходы — расходов. Пользовательские категории также разделены по типу записи. Существующие записи не изменяются.
- **Прогноз выбранного месяца.** Крупная сумма в разделе «Взгляд вперёд» показывает остаток на конец выбранного месяца. Выберите месяц на графике, в таблице или мобильном списке. Кнопки 3 / 6 / 12 задают диапазон отображения.

## Установка и обновление

- Windows x64: `Vpered-Setup-1.2.0.exe`.
- Android 7+: `Vpered-1.2.0-Android.apk`. Подписан тем же ключом, что и 1.1.0, с увеличенным versionCode.
- Устанавливайте поверх предыдущей версии. Перед обновлением сохраните резервную копию через «Сохранить файл». Не удаляйте старое приложение, чтобы не потерять его локальные данные.
- Windows-установщик не имеет сертификата издателя. Android APK предназначен для установки из файла.

Приложение полностью локальное. Без банковских подключений, облака и необходимости подключать телефон к ПК. iPhone исключён из текущего плана.

## Проверки

32 финансовых теста, TypeScript/Vite build и проверка Windows-приложения в отдельном профиле: загрузка бюджета 1.1, сохранение темы после перезапуска, RU/EN, категории, выбор месяца на графике/в таблице/на мобильном экране. Android release build и проверка APK-подписи. На физическом Android-устройстве версия ещё не проверена.
